Denne mappen inneholder ekstra bilder tatt under arbeidet med bacheloroppgaven.

Bildene viser generelle deler av prosjektgjennomføringen, som produksjon, testing, prøvehåndtering, utstyr, oppsett og andre aktiviteter som ble utført underveis i prosjektet.

Bildene er ikke nødvendigvis brukt direkte som figurer i hovedrapporten, men er lagt ved som supplerende dokumentasjon for å vise arbeidsprosessen og praktisk gjennomføring.

Innholdet i denne mappen skal derfor forstås som støttemateriale, ikke som selvstendige resultater eller formelle rapportfigurer.
