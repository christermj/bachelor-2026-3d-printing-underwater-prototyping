Denne mappen inneholder ekstra datafiler som er omarbeidet, strukturert eller brukt som grunnlag for figurer, tabeller og vurderinger i hovedrapporten.

Filene er ikke nødvendigvis presentert direkte i rapporten, men er tatt med for å dokumentere hvordan datagrunnlaget er behandlet og hvordan informasjonen i rapporten er kommet frem.

Innholdet i denne mappen skal derfor forstås som støttefiler og rå-/mellomdata, ikke som selvstendige resultater.
